# VEO - Computer Vision Assistant
This branch contains **partial code** for demonstration purposes.
The full project will be uploaded in stages.


VEO Vision is an accessibility tool that uses real-time computer vision to help blind or visually impaired people understand their surroundings.

The app identifies objects using an offline neural network optimized for Android and provides instant voice feedback. It requires no internet connection at any time — all processing happens locally on your device, ensuring privacy, speed, and full autonomy.

Designed specifically for users with visual impairments, VEO Vision requires no setup or configuration. It works immediately out-of-the-box, and with a simple double-tap gesture you can start or stop the object recognition engine instantly.

The app automatically adjusts to dark environments by activating the phone’s flashlight when needed, and it runs smoothly even on modest devices thanks to its native C/C++ engine.

✨ Features
Real-time object detection

Native engine in C/C++ (JNI)

Clear and accessible voice announcements

Automatic flashlight activation

Fully offline operation — no internet required

Zero data collection

No configuration needed; control the engine with a simple double-tap

Runs efficiently even on mid-range devices
